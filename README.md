# Robotics Simulation

A Python tool for exploring linear state-space systems. It checks stability, plots frequency response, and simulates the output for step or sinusoidal inputs.

## Requirements

- Python 3
- NumPy, SciPy, and Matplotlib

## Run

```bash
python3 -m pip install numpy scipy matplotlib
python3 MMMzad1final.py
```

Enter the system coefficients when prompted, then choose a step or sinusoidal input to view the time-domain response.
